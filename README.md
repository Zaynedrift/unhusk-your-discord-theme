# Unhusk Your Discord
this is a discord theme that gets rid of all the useless discord clutter, no more annoying things like needing to open someone's profile fully to see their whole bio!

unclutter your discord with unhusk

# How to Install
- Open the Themes tab on your vencord/vesktop
- Click "Edit QuickCSS"
- Paste this line of code into quickcss:  
```@import "https://raw.githubusercontent.com/Zaynedrift/unhusk-your-discord-theme/refs/heads/main/unhusk.css";```
- Enjoy a greater discord
